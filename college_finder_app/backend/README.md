# backend/

Plain Python modules (no classes except one exception type) that `app.py`
wires into Flask routes. Each file has one responsibility; nothing here
imports Flask itself.

## Step 1 — college search

### `scorecard.py`
Client for the College Scorecard API (`api.data.gov`).

- `list_states()` — every US state + DC as `{"abbr", "name"}`, sorted by name.
- `normalize_state(state)` — accepts `"Texas"` or `"TX"`, returns the
  2-letter abbreviation. Raises `ValueError` if unrecognized.
- `fetch_schools(state_abbr, fields, api_key, per_page=100)` — pages
  through every school in a state, requesting the given API field names
  (always includes `id`). Prefixes `https://` onto any `*_url` field
  missing a scheme. Raises `requests.HTTPError`/`RequestException` on
  failure.

### `cache.py`
Per-state on-disk cache of fetched Scorecard fields, at
`cache_data/state_schools/<STATE>.json`. Lets the app avoid re-fetching fields it
already has for a state.

An explicit `cache_dir` overrides the state-school directory itself;
files are stored directly in that directory.

- `load(state_abbr, cache_dir=None)` — returns
  `{"fetched_fields": set[str], "schools": {unitid_str: {field: value}}}`,
  or an empty structure if no cache file exists yet.
- `save(state_abbr, cache, cache_dir=None)` — persists a cache dict to disk.
- `missing_fields(cache, requested_fields)` — which of `requested_fields`
  aren't in `cache["fetched_fields"]` yet.
- `merge_rows(cache, fetched_field_names, rows)` — merges freshly-fetched
  rows into the cache (keyed by school id), unioning in the field names
  that were just fetched. Mutates and returns `cache`.
- `rows_for_fields(cache, requested_fields)` — cached schools reduced to
  `id` + the requested fields (missing fields come back as `None`).

### `field_catalog.py` + `field_catalog.json`
The catalog of every College Scorecard field the app exposes in its field
picker, grouped into categories, plus lookup tables for fields whose raw
value is a numeric code (e.g. `school.ownership`). `field_catalog.json` is
generated by `API_Documentations/build_field_catalog.py` at the repo root
— don't hand-edit it.

- `load_catalog(path=None)` — loads and returns the catalog dict:
  `{"categories": [{"key", "label", "fields": [{"api_field", "label", "is_url"}]}], "value_labels": {api_field: {code_str: label_str}}}`.
  Defaults to the `field_catalog.json` next to this module.
- `all_fields(catalog)` — flattens `catalog["categories"]` into a single
  list of `api_field` names.
- `decode_row(row, catalog)` — given a school row `{api_field: raw_value}`,
  returns a copy with any coded field (per `value_labels`) replaced by its
  label string. Fields with no matching entry pass through unchanged.

## Step 2 — athletics staff finder

### `staff_finder.py`
Orchestrates the per-school staff lookup pipeline. This is the module the
other staff-finder files feed into.

- `find_staff_for_school(school_name, state, tavily_key, llm_provider_name=None)`
  — runs the full pipeline for one school: finds a general-athletics URL
  and a track & field/XC URL (Tavily search + LLM pick, falling back to
  Wikipedia), extracts staff from each, de-dupes, and fills in missing
  emails from bio pages. Never raises — any failure becomes a single row
  with `category: "error"` and a `notes` field (API keys redacted).
  Returns `{"school_name", "state", "staff": [rows]}`.
- Internal helpers (not used outside this module):
  `_run_pipeline`, `_find_url` (returns `(url, confirmed)` — `confirmed`
  is `False` for a Wikipedia-fallback URL, which prevents it from forcing
  every row on that page to `category: "coach"`), `_extract_from_url`,
  `_dedupe` (merges rows by lowercased name; a `"coach"`-tagged row always
  wins the category), `_fill_missing_email` (only accepts a bio-page email
  if the bio page's own extracted name matches).

### `tavily_client.py`
Thin HTTP client for the two Tavily endpoints this feature uses.

- `search(query, api_key, max_results=5, timeout=30)` — POSTs to
  `/search`, returns the `results` list (each `{"url", "title", "content"}`).
- `extract(url, api_key, timeout=30)` — POSTs to `/extract`, returns the
  clean `raw_content` string for one URL (`""` if Tavily couldn't extract it).

Both raise `requests.RequestException` on a network/HTTP error; neither
catches exceptions itself — that's `staff_finder`'s job.

### `wikipedia_lookup.py`
Fallback URL source used only when Tavily search + the LLM don't produce
a confident directory URL for a school.

- `find_staff_link(school_name, timeout=15)` — searches Wikipedia for
  `"{school_name} athletics"`, then scans that article's external links
  for one containing `staff`/`coach`/`roster`/`directory`. Returns the
  first match, or `None`.
- Internal helpers: `_find_article_title`, `_external_links`.

### `llm_provider.py`
The single seam every other module goes through to call an LLM — nothing
else in this feature branches on provider.

- `CATEGORIES = {"coach", "admin", "sports_medicine", "sports_info"}` —
  the fixed classification enum (`"error"` is added separately by
  `staff_finder` for failed lookups, not by the LLM).
- `LLMError` — raised by `get_provider()` for an unrecognized provider name.
- `get_provider(override=None)` — resolves to `"openai"` or `"ollama"`:
  `override` if given, else the `LLM_PROVIDER` env var, default `"openai"`.
- `pick_url(school_name, purpose, search_results, provider=None)` —
  `purpose` is `"general_athletics"` or `"track_field"`. Asks the LLM to
  choose the best URL from a list of Tavily search results. Returns
  `{"url": str|None, "confidence": "high|medium|low|none", "notes": str}`.
  Degrades to `{"url": None, "confidence": "none", ...}` on any parse or
  network failure, or if there were no search results to choose from.
- `extract_staff(school_name, page_text, source_url, provider=None)` —
  asks the LLM to pull categorized staff rows out of already-extracted
  page text. Drops any row the LLM can't place into `CATEGORIES`. Returns
  `[]` for blank input or an unparseable response.
- `OPENAI_MODEL = "gpt-4.1-mini"`, `OLLAMA_MODEL` (default `"mistral-small3.1:24"`,
  overridable via the `OLLAMA_MODEL` env var; talks to `OLLAMA_HOST`,
  default `http://localhost:11434`).

### `staff_cache.py`
Per-school on-disk cache of staff lookup results, mirroring `cache.py`'s
pattern, at `cache_data/staff/<STATE>/<school-slug>.json`.

- `load(state_abbr, school_name, cache_dir=None)` — returns the cached
  `{"school_name", "state", "fetched_at", "staff"}` dict, or `None` if
  nothing is cached.
- `save(state_abbr, school_name, staff_rows, cache_dir=None)` — writes the
  result to disk (slugified filename) and returns the saved record.
- `is_error_only(staff_rows)` — true if `staff_rows` is non-empty and every
  row is a lookup-failure row (`category: "error"`).
- `is_usable(cached)` — true if a `load()` result is on the current
  `CACHE_VERSION` and isn't `is_error_only`, i.e. a fresh lookup can be
  skipped in favor of it. Shared by `staff_jobs.py` and
  `scripts/step2_find_staff.py` so both "skip if already found" checks agree.
- `_slugify(name)` — lowercases and hyphenates a school name for use as a
  filename.

### `staff_jobs.py`
In-memory background job tracker for a batch of schools requested from
the UI. Not persisted — an app restart loses any in-flight job.

- `start_job(schools, refresh=False, run_in_thread=True)` — registers a
  job for a list of `{"name", "state"}` dicts and returns a `job_id`
  immediately. Processes schools sequentially in a background thread
  (or synchronously, before returning, when `run_in_thread=False` — used
  by tests and by `app.py` whenever `app.testing` is set).
- `get_status(job_id)` — returns a snapshot copy of the job's current
  state (`{"done", "total", "results", "finished"}`), or `None` if the
  `job_id` is unknown.
- `_run_job(job_id, schools, refresh)` — the worker function: for each
  school, serves from `staff_cache` (via `is_usable`) unless `refresh` is
  set, otherwise runs `staff_finder.find_staff_for_school` and caches the
  result (via `is_error_only`). A per-school exception (bad cache file,
  missing name, etc.) becomes a single `category: "error"` row for that
  school rather than aborting the job. Always marks the job
  `"finished": True` in a `finally` block, even on an unexpected
  exception, so a poll never hangs forever.

See also `scripts/step2_find_staff.py` (documented in `scripts/README.md`) for
the standalone, resumable, usage-limit-aware CLI that runs this same
pipeline over every school in `cache_data/state_schools/`.
